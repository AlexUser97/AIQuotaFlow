# AIQuotaFlow — как это работает глазами пользователя

---

## Идея в одном абзаце

Ты держишь несколько AI-аккаунтов. Когда упираешься в лимит на одном — переключаешься на другой. Проблема: ты не помнишь когда какой сбросится, и у тебя в голове каша из трёх Claude Pro с непонятными именами. AIQuotaFlow решает это как планировщик стиральных машин: сам говоришь боту «занял этот аккаунт», бот считает время и присылает уведомление когда можно возвращаться.

---

## Первый запуск

Открываешь бот, пишешь `/start`. Бот приветствует тебя и показывает четыре кнопки:

```
📋 Мои подписки    📊 Статусы
⚙️ Настройки       ❓ Помощь
```

Больше ничего. Никаких лишних разделов.

---

## Добавляешь свои аккаунты

Жмёшь **📋 Мои подписки → ➕ Добавить**.

Бот задаёт три обязательных вопроса:

**1. Провайдер** — выбираешь кнопкой:
`Claude | ChatGPT | Gemini | Grok | Custom`

**2. Название аккаунта** — пишешь сам:
Можешь написать email: `ivan.work@gmail.com`
Или просто: `Claude работа`, `GPT Research`, `#2`

**3. Тариф** — выбираешь кнопкой:
`Free | Pro | Max | Team | Custom`

Всё. Аккаунт создан. Бот предложит добавить детали — можешь сразу или потом:

```
✅ Аккаунт добавлен!

Хочешь добавить детали?
📧 Email   🎯 Цели
📅 Дата подписки   📝 Заметки
⏭ Пропустить
```

---

## Про email — важный момент

Email необязателен, но рекомендуется если у тебя несколько аккаунтов одного провайдера.

Без email твой список выглядит так:
```
🟢 Claude #1
🟡 Claude #2
🔴 Claude #3
```
И ты всё равно не знаешь на какой переключаться.

С email:
```
🟢 ivan.work@gmail.com
🟡 ivan.side@gmail.com — сброс через 2ч 47м
🔴 ivan.old@gmail.com — недельный лимит
```
Сразу понятно. Пароль бот не просит и не хранит — только email как текстовую метку.

---

## Три цвета — вся логика

**🟢 Зелёный** — аккаунт свободен, используй прямо сейчас.

**🟡 Жёлтый** — cooldown, но восстановится в течение 24 часов. Скоро можно.

**🔴 Красный** — cooldown дольше суток, или исчерпан недельный лимит, или подписка истекла. Не скоро.

---

## Когда упёрся в лимит

Открываешь нужный аккаунт, жмёшь **⏳ Cooldown**. Выбираешь время:

```
1ч    3ч    5ч ⭐
6ч    12ч   24ч
✍️ Своё время
```

Звёздочка на 5 часах — это рекомендация для Claude Pro, у него rolling window именно 5 часов. Для других провайдеров выбираешь нужное.

Бот ставит таймер. Аккаунт становится 🟡. Когда время выйдет — придёт уведомление:

```
🟢 ivan.side@gmail.com свободен!
Claude Pro — квота восстановилась.
Переключайся.
```

И статус сам станет зелёным.

## Workspace — фильтр по задачам

Допустим у тебя три Claude Pro: один для диссертации, два для SaaS-проекта. Вместо того чтобы помнить какой для чего — создаёшь workspace.

**Создание workspace:**
Идёшь в настройки аккаунта → 🎯 Цели → создаёшь новый workspace с любым названием:
`SaaS проект`, `Диссертация`, `🎓`, `работа` — что угодно.

**Привязка аккаунтов:**
В каждом аккаунте выбираешь к каким workspace он относится. Один аккаунт может быть в нескольких.

**Как это используется:**
Открываешь **📊 Статусы**. Вверху кнопки-фильтры:

```
Все аккаунты | SaaS проект | Диссертация
```

Жмёшь `SaaS проект` — видишь только аккаунты для этой задачи:

```
📊 SaaS проект

🟢 Доступны сейчас:
• ivan.work@gmail.com — Claude Max

🟡 Восстановятся в течение 24ч:
• ivan.side@gmail.com — через 2ч 47м
```

Сразу понятно что использовать, ничего лишнего.

---

## Уведомления

Бот присылает три вида уведомлений:

**1. Cooldown завершился** — квота восстановилась, можно работать.

**2. Подписка скоро истекает** — напоминание за N минут до конца (настраивается).

**3. Подписка истекла** — аккаунт помечается красным автоматически.

Уведомления можно отключить в настройках. Время напоминания настраивается: за 5 / 15 / 30 / 60 минут.

---

## Настройки

```
⚙️ Настройки

🌍 Часовой пояс: Europe/Moscow
⏰ Напоминание за: 15 минут
🔔 Уведомления: ВКЛ
🕐 Формат времени: 24ч
```

Часовой пояс влияет на то как отображается время восстановления — всё переводится в твоё местное время.

---

## Чего бот НЕ делает

Это важно понимать:

- Не логинится в твои аккаунты
- Не проверяет лимиты автоматически (ты сам говоришь когда упёрся)
- Не переключает аккаунты за тебя
- Не хранит пароли, токены, cookies
- Не знает сколько промптов у тебя осталось

Это **ручной трекер**. Ты сам нажимаешь кнопку когда уткнулся в лимит. Бот просто считает время и напоминает.

---

## Типичный рабочий сценарий

```
1. Работаешь на ivan.work@gmail.com (Claude Max)
2. Уткнулся в лимит
3. Открываешь бот → аккаунт → ⏳ Cooldown → 5ч
4. Переключаешься на ivan.side@gmail.com
5. Через 5 часов приходит уведомление: work снова свободен
6. Переключаешься обратно
```

Вот и всё.

---

## Технически

- Работает 24/7 на сервере
- Данные хранятся в файле на сервере (SQLite)
- Таймеры переживают перезапуск сервера — уведомление придёт даже если бот перезапускался
- Поддерживает несколько пользователей — каждый видит только свои аккаунты
